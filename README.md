# 传奇 BOSS 计时工具

使用 PySide6 / Qt Widgets 开发的原生 Windows 桌面程序。默认导入提供的 `boss_config.json`，包含 4 个分类、60 个地图和 311 条 BOSS 资料。界面使用系统默认界面字体，统一为 10 pt，随 Windows 缩放比例适配。

窗口和控件使用 Qt 自动选择的 Windows 原生样式，滚动条和表头保持系统默认外观。所有普通按钮（含弹窗按钮）保留平台样式的背景、尺寸、圆角和交互效果，仅省略默认与焦点强调装饰，避免出现紫色边框。复选框局部采用 13 像素黑白小方框；普通行显示黑色勾号，蓝色选中行显示白色边框和白色勾号。树形目录使用同尺寸的 SVG 方框加号和减号表示收起与展开。列表选中后整行连续填充蓝色，列间无选中缝隙；计时及加载配置列表的行高为 24 个逻辑像素。

## 直接运行

双击 `dist/传奇BOSS计时器.exe`，无需另外安装 Python 或 PySide6。它是单文件 Windows x64 程序，可以单独复制到其他目录运行。

源码环境已配置好时，也可双击项目根目录的 `start.bat`。

## 使用方式

1. 左侧按“分类 → 地图 → BOSS”显示，支持展开、收起和勾选。没有展开历史时，所有层级默认收起；恢复默认配置后也全部收起。双击 BOSS 编辑名称、刷新时间（秒）和显示提示文本；确认后立即保存。提示文本显示在右侧条目的鼠标悬停提示中。
2. 右击左侧 BOSS，选择“开始计时”。刷新时间必须大于 0；同一分组、同一地图的同名 BOSS 最多存在一条，不同地图的同名 BOSS 可以同时计时，重复操作会定位已有条目。
3. “全部开始”仅恢复右侧列表内已暂停的计时，不添加左侧项目；正在运行和已到期的计时不会重置。添加 BOSS 请使用左侧右键菜单的“开始计时”。
4. 右侧默认按剩余时间升序排列。右键可删除、暂停或开启计时；只有暂停后显示“开启计时”。“全部暂停”冻结所有运行中的计时。双击右侧任意计时行会询问是否重新倒计时，确定后从完整刷新间隔重新开始；取消保持原状态，重置不会新增重复条目。
5. 到期显示红色 `00:00`，120 秒后自动删除。到期不会自动重开一轮；需要重新计时时，删除旧条目后从左侧开始。
6. 主窗口是否置顶由项目根目录 `boss_config.json` 顶层的 `topmost` 控制：`true` 表示置顶，`false` 表示普通窗口；缺失或类型错误时默认置顶。修改后需要重新启动程序。窗口位置、尺寸、分栏比例和目录展开状态会在正常退出时保存。窗口固定为不透明，不提供透明度控制；列表下方不显示操作提示或状态栏。
7. “恢复默认配置”位于“加载配置”之后。确认后恢复默认 BOSS 信息和勾选状态，清空右侧计时及所有已保存方案，重置窗口布局、菜单展开历史和升序排序，并清除新旧数据目录内的配置、备份及残留配置临时文件。日志和运行锁保留，根目录默认文件不会被修改。

暂停后，“下次刷新时间”显示“已暂停”，剩余时间保持不变。恢复时从冻结的剩余秒数继续计算。计时基于系统实际时刻，电脑休眠后运行中的计时仍会继续流逝。

## 保存和加载配置

- 右侧列表中的项目均为已开始的计时，保存配置时会保存全部项目。
- 手动创建列表后点击“保存配置”，输入名称，新增带独立 UUID 的方案。
- 每次保存均新增独立配置并生成新的 ID，允许同名，不覆盖已有配置。
- 加载窗口显示名称和条目数；悬停可查看方案 ID。点击加载后直接替换当前列表并重新开始计时，不再询问保存未保存的修改。
- 加载时按怪物名称、分组和地图匹配当前 BOSS 资料，使用最新刷新间隔，从加载时刻重新开始完整倒计时，不沿用保存时的剩余时间、暂停或到期状态。
- 无法匹配、刷新时间无效或怪物重名时，会提示具体项目并保留当前列表。修改左侧资料不会重置正在运行的倒计时。

关闭窗口时直接退出，不询问保存计时方案，也不会自动覆盖已保存的方案。需要保留右侧列表时，请先手动点击“保存配置”。加载配置会直接替换右侧列表并从完整时长重新开始。程序不会在启动时自动加载上次方案，请使用“加载配置”选择。

## 数据位置与备份

默认数据目录：`%LOCALAPPDATA%\LegendBossTimer\`。首次启动会从旧的双层目录 `LegendBossTimer\LegendBossTimer` 逐文件迁移缺失的配置；新目录已有文件时优先保留新文件。正常迁移保留旧文件供回退，“恢复默认配置”会同时清理两处的配置和备份，避免再次导入旧数据。

| 文件 | 用途 |
| --- | --- |
| `boss_catalog.json` | 用户修改的 BOSS 资料与勾选状态；启动时优先读取 |
| `profiles.json` | 带独立 ID 的计时方案 |
| `settings.json` | 窗口和显示设置 |
| `*.json.bak` | 对应文件上一次成功保存的内容 |
| `app.log` | 错误日志，自动轮转 |

原始微信附件不会被修改。根目录 `boss_config.json` 是默认 BOSS 资料及置顶参数来源，正常操作和退出不会修改它；打包时嵌入 EXE。源码和发布版均优先读取本地 `boss_catalog.json`，不存在时使用默认资料。界面编辑和勾选保存到本地文件；修改默认 BOSS 资料后，需恢复默认配置才会替换已有的本地资料。置顶参数始终从默认文件读取，修改后需重启。识别关键词、语音和游戏窗口识别配置不参与本程序功能。

保存采用同目录临时文件、完整写入后原子替换，失败时保留原文件。若配置损坏，程序提示具体路径，不会自动用空配置覆盖。恢复时先关闭程序，备份损坏文件，再把对应 `.bak` 复制回 `.json`。同一数据目录只允许运行一个实例，避免相互覆盖。

可使用 `传奇BOSS计时器.exe --data-dir "D:\BossTimerData"` 指定其他数据目录。

## 源码运行与构建

需要 Windows x64、Python 3.11 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\start.bat
```

日常修改后直接启动源码预览，不自动打包：

```powershell
.\.venv\Scripts\python.exe run.py
```

确认效果后手动打包：

```powershell
.\build.ps1
```

构建脚本只执行打包，输出 `dist/传奇BOSS计时器.exe`；不自动运行测试或启动打包程序。`dist` 仅保留这一个可执行文件，说明文档保留在项目根目录。

若本机限制 PowerShell 脚本，可在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm BossTimer.spec
```

需要时可单独运行测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

源码渲染验证（使用临时数据，不修改个人配置）：

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe run.py --smoke-test "$PWD\artifacts\preview.png"
```

## 代码组织

```text
src/boss_timer/
  app.py           程序入口、全局字体、独立数据目录及异常日志
  domain/          业务数据、状态、名称唯一性规则
  services/        计时调度、暂停恢复、方案新增与修改
  repositories/    JSON 兼容解析、原子写入及备份
  ui/
    main_window.py 原生窗口布局与信号连接
    models/        树形菜单、表格视图适配
    dialogs/       BOSS 编辑、方案保存、方案加载
  resources/       内置初始 BOSS 配置
tests/             核心计时、存储、界面交互测试
```

业务服务不依赖 Qt，使用可注入时钟测试时间边界；界面只使用一个 QTimer 每秒刷新。表格按数值剩余时间稳定排序，重新排序时保持选中条目。左侧使用 Qt 自带的 QTreeView 和 QStandardItemModel，无额外界面组件库。
