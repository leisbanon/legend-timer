# 传奇 BOSS 计时工具

使用 PySide6 / Qt Widgets 开发的原生 Windows 桌面程序。默认导入提供的 `boss_config.json`，包含 4 个分类、60 个地图和 311 条 BOSS 资料。界面使用系统默认界面字体，统一为 10 pt，随 Windows 缩放比例适配。

窗口和控件使用 Qt 自动选择的 Windows 原生样式，滚动条、表头和按钮保持系统默认外观。复选框局部采用 13 像素黑白小方框；普通行显示黑色勾号，蓝色选中行显示白色边框和白色勾号。树形目录使用同尺寸的 SVG 方框加号和减号表示收起与展开。列表选中后整行连续填充蓝色，列间无选中缝隙；计时及加载配置列表的行高为 24 个逻辑像素。

## 直接运行

双击 `dist/BossTimer.exe`，无需另外安装 Python 或 PySide6。它是单文件 Windows x64 程序，可以单独复制到其他目录运行。

源码环境已配置好时，也可双击项目根目录的 `start.bat`。

## 使用方式

1. 左侧按“分类 → 地图 → BOSS”显示，支持展开、收起和勾选。双击 BOSS 编辑名称、刷新时间（秒）和显示提示文本；确认后立即保存。提示文本显示在右侧条目的鼠标悬停提示中。
2. 右击左侧 BOSS，选择“开始计时”。刷新时间必须大于 0；同名 BOSS 在右侧最多存在一条，跨地图同名也不允许重复，重复操作会定位已有条目。
3. “全部开始”添加左侧已勾选的 BOSS，并恢复右侧已暂停的计时。按左侧目录顺序添加，同名只保留先遇到的条目；已存在的计时不会重置。原文件全部勾选，首次批量开始前可先按需取消分类或地图的勾选。
4. 右侧默认按剩余时间升序排列。右键可删除、暂停或开启计时；只有暂停后显示“开启计时”。“全部暂停”冻结所有运行中的计时。
5. 到期显示红色 `00:00`，120 秒后自动删除。到期不会自动重开一轮；需要重新计时时，删除旧条目后从左侧开始。
6. 主窗口是否置顶由 `src/boss_timer/resources/boss_config.json` 顶层的 `topmost` 控制：`true` 表示置顶，`false` 表示普通窗口；缺失或类型错误时默认置顶。修改后需要重新启动程序。窗口位置、尺寸、分栏比例和目录展开状态会在正常退出时保存。窗口固定为不透明，不提供透明度控制；列表下方不显示操作提示或状态栏。

暂停后，“下次刷新时间”显示“已暂停”，剩余时间保持不变。恢复时从冻结的剩余秒数继续计算。计时基于系统实际时刻，电脑休眠后运行中的计时仍会继续流逝。

## 保存和加载配置

- 右侧行首复选框只控制该条目是否保存，不控制计时。新增条目默认勾选。
- 手动创建列表后点击“保存配置”，输入名称，新增带独立 UUID 的方案。
- 加载方案后再次保存，修改原方案并保留 ID。勾选“另存为新配置”并填写不同名称，可以创建副本。
- 加载窗口显示名称、条目数和修改时间；悬停可查看方案 ID。加载会替换当前列表，未保存修改可先保存、放弃或取消。
- 运行条目保存绝对刷新时刻，加载时继续按实际时间计算；暂停条目保存冻结的剩余秒数。加载时已到期超过 120 秒的条目会被清理。
- 修改左侧资料不会重置当前倒计时。已保存方案加载时，按稳定的 BOSS ID 同步最新名称、提示及刷新间隔；改名导致右侧重名时会阻止操作。

关闭窗口时直接退出，不询问保存计时方案，也不会自动覆盖已保存的方案。需要保留右侧列表时，请先手动点击“保存配置”。加载其他配置前，仍会对未保存修改提供保存、放弃或取消选项。方案内的运行时间不会在关闭程序后冻结。程序不会在启动时自动加载上次方案，请使用“加载配置”选择。

## 数据位置与备份

默认数据目录：`%LOCALAPPDATA%\LegendBossTimer\LegendBossTimer\`。

| 文件 | 用途 |
| --- | --- |
| `boss_catalog.json` | 编辑后的 BOSS 资料、左侧勾选状态；首次修改时生成 |
| `profiles.json` | 带独立 ID 的计时方案 |
| `settings.json` | 窗口和显示设置 |
| `*.json.bak` | 对应文件上一次成功保存的内容 |
| `app.log` | 错误日志，自动轮转 |

原始微信附件不会被修改。内置 `src/boss_timer/resources/boss_config.json` 只作为首次导入来源，原文件中的识别关键词、语音和游戏窗口识别配置不参与本程序功能。

保存采用同目录临时文件、完整写入后原子替换，失败时保留原文件。若配置损坏，程序提示具体路径，不会自动用空配置覆盖。恢复时先关闭程序，备份损坏文件，再把对应 `.bak` 复制回 `.json`。同一数据目录只允许运行一个实例，避免相互覆盖。

可使用 `BossTimer.exe --data-dir "D:\BossTimerData"` 指定其他数据目录。

## 源码运行与构建

需要 Windows x64、Python 3.11 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\start.bat
```

日常修改后直接启动源码预览，不自动打包：

```powershell
.\.venv\Scripts\python.exe run.py
```

确认效果后手动打包：

```powershell
.\build.ps1
```

构建脚本只执行打包，输出 `dist/BossTimer.exe`；不自动运行测试或启动打包程序。`dist` 仅保留这一个可执行文件，说明文档保留在项目根目录。

若本机限制 PowerShell 脚本，可在项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm BossTimer.spec
```

需要时可单独运行测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

源码渲染验证（使用临时数据，不修改个人配置）：

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv\Scripts\python.exe run.py --smoke-test "$PWD\artifacts\preview.png"
```

## 代码组织

```text
src/boss_timer/
  app.py           程序入口、全局字体、独立数据目录及异常日志
  domain/          业务数据、状态、名称唯一性规则
  services/        计时调度、暂停恢复、方案新增与修改
  repositories/    JSON 兼容解析、原子写入及备份
  ui/
    main_window.py 原生窗口布局与信号连接
    models/        树形菜单、表格视图适配
    dialogs/       BOSS 编辑、方案保存、方案加载
  resources/       内置初始 BOSS 配置
tests/             核心计时、存储、界面交互测试
```

业务服务不依赖 Qt，使用可注入时钟测试时间边界；界面只使用一个 QTimer 每秒刷新。表格按数值剩余时间稳定排序，重新排序时保持选中条目。左侧使用 Qt 自带的 QTreeView 和 QStandardItemModel，无额外界面组件库。
